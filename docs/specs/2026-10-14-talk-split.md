# Разрез склеенного кластера по плиткам Толка — спецификация (тикет 04)

Стенд (тикет 02) показал: при любом пороге похожести остаётся 36–48 кластеров, в которых два человека
по плиткам держат по ≥ 0,3 реплик каждый. Голоса похожи, порог их не разведёт; но интерфейс встречи видел,
кто говорил, — этим и режем.

## Правило

На финализации (и в `refinalize`), после перекластеризации и пересчёта `Rec.talk` по всей ленте:
для каждого кластера считаем, какие имена плиток накрыли его длинные реплики. Если два и более имени держат
по `talk_split_share` (0.3) названных реплик каждое — кластер склеен. Реплики каждого такого имени становятся
своим кластером (самое частое имя оставляет старую метку), остаток — безымянные реплики и редкие имена —
уходит к ближайшему из новых центроидов по косинусу (он и так лежал в этом кластере). Короткие реплики
(без отпечатка или короче `min_embed_s`) в счёт не идут и метку соседа сохраняют. `talk_split_share: 0`
выключает разрез. Реализация — `speakers.split_by_names` (чистая), хук — `pipeline.split_merged_clusters`.

## Проверка на стенде

Разрез по тем же именам, по которым потом меряется согласие, — круговая метрика (чистота названных реплик
станет 1.0 по построению). Поэтому у `bench-diar` есть `--holdout`: имена чётных размеченных реплик идут
в разрез, метрика считается по нечётным. Сравнивать прогоны только с одинаковым `--holdout`.

## Не делаем

- Разрез во время записи (онлайн-кластеризация): имена всё равно раздаются на финализации.
- Разрез по библиотеке голосов — только по плиткам Толка.

## Результат на стенде (14.10.2026, holdout, 35 сессий, 1846 реплик в проверочной половине)

| прогон | чистота | цельность | кластеров/говоривших | склеек | расколов |
|---|---|---|---|---|---|
| без разреза | 0,869 | 0,835 | 206/165 | 29 | 28 |
| разрез, доля 0,3, без минимума реплик | 0,880 | 0,829 | 230/165 | 26 | 29 |
| **разрез, доля 0,3, ≥3 реплики на половину** | **0,879** | 0,829 | 213/165 | 26 | 29 |

Ни одна сессия не ухудшилась по чистоте (лучше 8 из 35, остальные без изменений). Выигрыш честной метрики скромный —
в разрез идёт только половина имён; в бою идут все, и названные реплики в разрезанном кластере получают своё имя по
построению. Минимум три реплики на половину даёт тот же выигрыш при 17 лишних кластерах меньше — оставлен умолчанием
(`talk_split_min_count: 3`). Склейки, которые остались (26), — кластеры, где одно из имён ниже 0,3 или реплик мало:
это уже не разрез, а предел того, что видят плитки.
