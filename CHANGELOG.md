# Что нового

## 2026-10-21

- **Настройки по разделам.** «Настройки…» теперь окно с пятью разделами на панели сверху: Владелец, Куда пишет, Запись, Приватность, Агент. Папки транскриптов и заметок встреч, хранение аудио и наблюдение за участниками Толка больше не нужно править в файлах.
- Под каждым путём видно, есть ли такая папка; вольт, приватную папку и папку контекста можно выбрать через Finder.
- Окна приватности задаются строками «день · с · по» вместо текстового формата; окна, которые транскрибатор не может прочитать, сохраняются как есть и показываются предупреждением.
- **Свой агент.** В разделе «Агент» задаётся команда любого агента (он читает вопрос со входа и пишет ответ в вывод), папка контекста проектов и время ожидания; кнопка «Проверить» спрашивает агента одним словом и показывает, ответил ли он. Агент выбирается из списка найденных у тебя (Claude Code, Codex) — с уже правильной командой; «Своя команда…» — для остальных.
- **Вопросы агенту во время встречи.** Окно встречи перерисовано: плашка записи, говорящие цветом, действия иконками. Внизу — поле вопроса: агент получает текст встречи, распознанный к этому моменту, и все прошлые вопросы этой встречи; ответ выезжает листом поверх транскрипта, лист сворачивается. Тумблер «проекты» запускает агента из папки контекста, чтобы он видел твои заметки; без него агент видит только встречу. Агенты из списка отвечают только на чтение — ничего не меняют в файлах.
- Ответ агента отображается с разметкой: таблицы — настоящие, с рамками и цифрами по правому краю, списки с отступами, заголовки, цитаты, блоки кода. Агента просят отвечать под узкое окно: короткие абзацы и списки, таблица — только для чисел.
- Если по встрече задавали вопросы, после её окончания рядом с транскриптом появляется файл `Agent-…md` с вопросами и ответами. Приватной записи вопросы недоступны.

## 2026-10-19

- **Текст встречи прямо во время записи.** Клик по круглой кнопке записи открывает окно с текстом, распознанным к этому моменту. Окно обновляется само раз в пару секунд и держится у последней реплики; если отмотать вверх, прокрутка не прыгает. Текст можно выделить и скопировать. Распознавание идёт блоками, поэтому текст отстаёт от речи примерно на минуту, а вместо имён до конца записи стоят «Me» и «Speaker N» — имена подставляются при финализации.
- Действия, которые раньше были в меню кнопки (открыть заметку, остановить запись, скрыть кнопку), теперь внизу окна. Прежнее меню — по правому клику (или ctrl-клику) на кнопке.
- Воркер больше не перечитывает завершённые сессии на каждом проходе: между встречами он почти не грузит процессор.
